# Boldbean Coffee

A single-page website for a coffee brand: brown and yellow palette, torn-paper section dividers, popular flavors, benefits, reviews, blog cards and a newsletter footer.

## Run locally

Open `index.html` in a browser. No build step.

## Structure

- `index.html` holds the markup, styles and a small script (torn edges, cart counter, toast).
- Product, cup and bean artwork is inline SVG. Replace it with your own photos in an `images/` folder when ready.

## Notes

- Reviews are sample text. Replace them with real ones before launch.
- Prices are in USD. Change the `.price` values in the Popular flavors section for another currency.
